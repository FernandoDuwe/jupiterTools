# Jupiter - Versão 3.0

## _Ferramenta de automação de tarefas_

O Jupiter foi criado pensando em auxiliar as tarefas do desenvolvedor, controlando as tarefas e tempos utilizados em cada demanda, automatizando tarefas e facilitando o acesso a diferentes pastas ou aplicações.

## Customizações

Com uma linguagem interna customizada a partir do Pascal, o JPAS, você poderá customizar todo os comportamentos da aplicação, além de facilmente criar novos menus, novos atalhos e novas funcionalidades, conforme sua necessidade.

## Banco de dados

Focado no recolhimento de dados e na sua posterior utilização, o Jupiter está integrado a um banco de dados sqlLite. Sinta-se livre para criar novas tabelas ou editar a estrutura padrão da aplicação conforme a sua necessidade.

## Trabalhando com rotas

Todos os menus (menu superior, menu principal, menu de botão direito) podem ser customizados, a partir do cadastro de Routes. Com uma estrutura de caminhos, semelhante a uma estrutura de diretórios, o sistema encontrará os diferentes menus e renderizará eles em tela, conforme a necessidade.

## Criando atalhos

Semelhante aos menus, você poderá criar atalhos, bastando informar o atalho a ser executado e a macro correspondente.

## Trabalhando com Macros

Todos os comportamentos do sistema são disparados a partir de Macros JPAS. Caso você deseje modificar algum comportamento padrão, basta editar as macros já existentes no sistema. Se preferir, pode também criar macros novas, criando novas e incríveis funcionalidades dentro do sistema.

## Variáveis

Todas as configurações do sistema são centralizadas no cadastro de varíavéis. Você poderá acessar essas variáveis em qualquer ponto da aplicação, facilitando as customizações.

## Plataformas suportadas

O Jupiter pode ser executando nas plataformas Windows e Linux.
